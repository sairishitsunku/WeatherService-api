# Weather CLI

Simple Node.js command-line application that fetches the current weather for a given city.

## Usage

Run:

```
node index.js "London"
```

Expected output example:

```
Weather in London: 15°C, Clear sky
```

## Notes

- Uses the free wttr.in service (no API key required).
- Handles network errors and unexpected responses.
